# DailyQuestion Android Release Notes

Version: `1.0.29+37`
Date: `2026-04-08`

## 포함 내용
- 안드로이드 알림 설정을 개선해 시스템 알람 권한이 필요할 때 `허용` 안내 팝업을 먼저 보여주도록 수정했어요.
- 오늘의 질문 알림 카드에서 권한이 꺼져 있으면 실제로 왜 알림이 오지 않는지 바로 확인할 수 있게 안내를 보강했어요.
- 로그인 중 구글 로그인 버튼의 로딩 표현을 더 자연스럽게 다듬었어요.
- AI 리포트 기간 탭과 기간별 로컬 캐시, 실제 AI 호출 경로 안정화를 포함한 최근 리포트 개선 사항이 함께 반영돼요.
