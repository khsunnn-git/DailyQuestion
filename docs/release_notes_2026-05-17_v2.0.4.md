# DailyQuestion Release Notes

Version: `2.0.4+43`
Date: `2026-05-17`

## 포함 내용
- 새싹 테마가 60번째 기록에서 레벨 1로 시작하고, 이후 새싹 테마 안에서 쌓인 기록 수에 따라 물고기와 같은 주기로 성장하도록 조정했어요.
- 홈, 나의 기록, 프로필 캐릭터 표시가 테마별 성장 주기를 같은 기준으로 사용하도록 정리했어요.
- 안드로이드 알림 안정성을 위해 배터리 최적화 제외 안내와 권한 요청 흐름을 추가했어요.
- 앱 복귀 시 알림 예약 상태를 다시 확인해 설정 변경 이후에도 예약 상태가 반영되도록 보강했어요.
- AI 리포트 집계, 캐시, 타임라인 흐름을 정리하고 관련 테스트를 보강했어요.
- 온보딩, 의견 보내기, 알림 권한 안내, 릴리즈/스토어 문서와 앱 리소스를 정리했어요.

## 스토어용 짧은 버전 노트
- 새싹 테마 성장 주기가 60번째 기록부터 새로 시작되도록 개선했어요.
- 안드로이드 알림이 더 안정적으로 도착하도록 배터리 최적화 안내를 추가했어요.
- AI 리포트와 설정 화면의 안정성을 높였어요.
