# DailyQuestion Release Notes

Version: `3.1.0+213`
Date: `2026-11-22`

## 포함 내용
- 새 캐릭터 4종이 추가됐어요: 공룡, 고양이, 우파루파, 뱁새. 이제 캐릭터가 모두 8종이에요.
- 회원가입할 때 함께 키울 캐릭터를 직접 고를 수 있어요. (약관동의 → 캐릭터 선택 → 닉네임 설정)
- 캐릭터를 60회 다 키우면 다음 캐릭터를 직접 골라요. 예전처럼 정해진 순서로 넘어가지 않고,
  8종 중 아무거나, 같은 캐릭터도 다시 고를 수 있어요.
- 다음 캐릭터를 고를 수 있기 7회 전부터 안내 팝업이 떠요. (새 디자인, 지금 테마 색상)
- 새 캐릭터마다 움직임이 있어요.
  - 공룡: 눈 깜빡임, 1레벨 알은 좌우로 뒤뚱
  - 고양이: 눈 깜빡임, 꼬리 살랑살랑
  - 뱁새: 눈 깜빡임, 둥둥 떠다니기, 4·5레벨 날갯짓
  - 우파루파: 물속처럼 둥둥, 눈 깜빡임
- 백구 눈 깜빡임 때 몸이 살짝 움직이던 현상을 고쳤어요.
- 기존 이용자는 지금 키우던 캐릭터를 그대로 이어서 키우고, 60회를 채우면 선택 화면을 만나요.
  (백구를 이미 다 키운 이용자는 업데이트 후 바로 선택 화면이 떠요)

## 스토어용 짧은 버전 노트
- 새 친구 4종(공룡·고양이·우파루파·뱁새)이 찾아왔어요!
- 이제 함께 키울 캐릭터를 직접 고를 수 있어요. 60일을 함께한 뒤에는 다음 친구도 마음대로 골라보세요.
- 새 친구들이 눈을 깜빡이고, 꼬리를 흔들고, 날갯짓을 해요.
