# DailyQuestion 1.0.28+36 Release Notes

배포일: 2026-04-07
대상: Android, iOS

## 스토어용 짧은 문안

- AI 리포트 영역의 주간, 월간, 분기, 연간 화면을 새 디자인으로 개선했어요.
- 기간별 AI 리포트 생성 흐름과 캐시 갱신을 안정화해 실제 AI 응답이 더 잘 반영되도록 수정했어요.
- 기록 내용의 주제를 더 잘 읽어 키워드를 자연스럽게 보여주도록 개선했어요.

## 상세 변경사항

- AI 리포트 더블탭 UI와 간격, 안내 문구를 최신 디자인에 맞게 정리했습니다.
- 주간 리포트는 선택한 월 안에서 최대 5주까지 확인할 수 있도록 개선했습니다.
- 월간, 분기, 연간 리포트가 기록 기간에 맞춰 더 자연스럽게 생성되도록 정리했습니다.
- AI 리포트 서버 연동을 점검하고, 배포 환경에서 기본 API 경로를 사용할 수 있게 보완했습니다.
- 기존 fallback 리포트가 저장되어 있더라도 AI 응답이 가능해지면 다시 AI 리포트로 갱신되도록 수정했습니다.
- 키워드 추출 품질을 높여 사용자가 작성한 내용의 주제가 더 잘 드러나도록 개선했습니다.

## QA 체크 메모

- Android App Bundle 빌드 확인
- iOS 배포용 빌드 확인
- AI 리포트 서버 health check 및 analyze 응답 확인
