# DailyQuestion Release Notes

Version: `3.0.2+212`
Date: `2026-11-06`

## 포함 내용
- 네 번째 테마 '백구'(보라)가 추가됐어요. 기록 180개부터 열리고, 레벨마다 꼬리를 흔들고 눈을 깜빡여요.
- 돌맹이 테마와 성장 단계가 추가됐어요.
- AI 리포트가 쓰신 글을 바탕으로 더 다정하게, 나에 대해 새로 알게 되는 이야기를 들려줘요. 닉네임을 불러 주고, 주간 리포트 요약도 AI가 직접 써요.
- 정확도가 낮던 키워드 문장을 리포트에서 뺐어요.
- Android release 빌드에서 알림 아이콘이 사라지던 문제를 고쳤어요.
- 쓰지 않는 화면과 이미지를 정리해 앱 용량을 줄였어요.
- 앱 사용 통계(Firebase Analytics)를 연결했어요.

## 스토어용 짧은 버전 노트
- 새 테마 '백구'가 찾아왔어요! 기록 180개를 채우면 꼬리를 흔드는 백구를 만날 수 있어요.
- AI 리포트가 내 글을 더 깊이 읽고, 나에게 맞는 회복 방법과 계절 활동을 추천해 줘요.
- 알림 아이콘 표시 문제를 고치고 앱을 더 가볍게 만들었어요.
