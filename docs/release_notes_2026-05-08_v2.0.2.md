# DailyQuestion Release Notes

Version: `2.0.2+41`
Date: `2026-05-08`

## 포함 내용
- 그린 테마 오픈 1주일 전부터 홈에서 새싹 테마 안내 팝업이 보이도록 추가했어요.
- 팝업에서 `오늘은 닫기`를 누르면 하루 동안 다시 보이지 않고, `확인`은 현재 세션에서만 닫히도록 정리했어요.
- 더보기 > 설정의 앱 버전 표기가 현재 배포 버전과 항상 동일하게 보이도록 바꿨어요.
- 사용자 의견 보내기를 앱 내부 저장 대신 메일 앱으로 연결해 바로 전달할 수 있게 정리했어요.
- 안드로이드 알림 권한 흐름을 다듬고, 실기기에서 바로 확인할 수 있는 `5초 뒤 테스트 알림` 기능을 추가했어요.

## 스토어용 짧은 버전 노트
- 그린 테마 오픈 안내 팝업을 추가했어요.
- 설정의 앱 버전 표시와 의견 보내기 흐름을 개선했어요.
- 안드로이드 알림 동작과 권한 안내를 안정화했어요.
