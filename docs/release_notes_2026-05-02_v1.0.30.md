# DailyQuestion Release Notes

Version: `1.0.30+38`
Date: `2026-05-02`

## 포함 내용
- 안드로이드에서 오늘의 질문 알림을 받으려면 `알림`과 `정시 알람` 권한을 모두 허용하도록 흐름을 정리했어요.
- 사용자가 설정한 시간에 오늘의 질문 알림이 오도록 맞추고, 설정 전에는 기본 시간 `오후 3:00`에 알림이 가도록 안정화했어요.
- 최종 성장 단계의 물고기 크기를 조정해 물방울 장식과 겹쳐 보이던 화면을 조금 더 자연스럽게 다듬었어요.
- AI 리포트는 실제 OpenAI 응답이 준비된 시점에만 보여주도록 정리했고, 월별 키워드 카드는 제거했어요.
