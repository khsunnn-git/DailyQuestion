# DailyQuestion Release Notes

Version: `2.0.5+44`
Date: `2026-05-31`

## 포함 내용
- Android에서 정확한 알람 권한이나 배터리 최적화 제외 권한이 없어도 앱 진입과 알림 예약이 막히지 않도록 수정했어요.
- 알림 권한만 필수로 보고, 정확한 알람/배터리 최적화 설정은 알림 안정성을 높이는 선택 설정으로 분리했어요.
- 정확한 알람 권한이 꺼져 있을 때도 inexact fallback 예약이 계속 유지되도록 보강했어요.
- 권한 안내 문구를 실제 동작에 맞게 조정했어요.

## 스토어용 짧은 버전 노트
- Android 알림 예약이 부가 권한 거절로 막히지 않도록 수정했어요.
- 알림 권한 안내와 예약 복구 흐름을 안정화했어요.
