# DailyQuestion Release Notes

Version: `2.0.3+42`
Date: `2026-05-10`

## 포함 내용
- 안드로이드 알림 권한 흐름을 정리해, 정확한 알람 권한이 없어도 일반 예약 알림은 계속 동작하도록 개선했어요.
- 알림 설정 화면의 실기기 테스트 알림 버튼을 제거했어요.
- 그린 테마로 전환된 뒤에는 새싹 테마 안내/오픈 팝업이 다시 뜨지 않도록 조정했어요.
- 의견 보내기는 메일 앱을 열지 않고 Firestore `feedback` 컬렉션에 바로 접수되도록 변경했어요.
- 의견 접수 데이터에는 카테고리, 내용, 답변 이메일, 사용자 UID, 앱 버전, 작성 시각이 함께 저장돼요.

## 스토어용 짧은 버전 노트
- 안드로이드 알림 예약 흐름을 안정화했어요.
- 그린 테마 전환 후 안내 팝업 노출을 정리했어요.
- 의견 보내기를 앱 안에서 바로 접수되도록 개선했어요.
